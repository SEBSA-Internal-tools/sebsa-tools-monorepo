# SEBSA Internal Tools

A centralized monorepo for SEBSA internal applications, shared components, and services.

## Applications

### SEBSA Employee Management Portal
- Frontend: Next.js
- Employee and profile management

### SEBSA Technical Review Portal
- Frontend: Next.js
- Backend: NestJS
- Technical assessments and review management

### SEBSA Project Management Tool
- Frontend: Angular
- Backend: NestJS
- Project planning and tracking

## Getting Started

```bash
npm install
npm run dev
```
